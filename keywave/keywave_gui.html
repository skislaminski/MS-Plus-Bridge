How to get the table onto the pedal (same file name and same ID as the KeyWave that is already on it):
  1. Back up the pedal (stomphacks: backup_pedal.py).
  2. Take KeyWave out of all patches.
  3. Remove the old KeyWave: pedal_diy.py uninstall with this KEYWAVE.ZD2.
  4. Install the new KEYWAVE.ZD2 from this folder (the .ZIC next to it belongs to it).
  5. Try it in an unsaved patch first, with AUTO SAVE off.
Saved knob settings still work: the knobs and the ID stay the same, only the table is new.
